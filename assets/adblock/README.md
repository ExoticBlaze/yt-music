# Bundled filters

`easylist.txt` is an unmodified snapshot from [The EasyList authors](https://easylist.to/), downloaded from https://easylist.to/easylist/easylist.txt. Its version, date and source commit are preserved in the file header.

The filter list is distributed under [Creative Commons Attribution-ShareAlike 3.0 Unported](https://creativecommons.org/licenses/by-sa/3.0/), as allowed by the authors' [dual licensing terms](https://easylist.to/pages/licence.html). Attribution and this license apply to the list; application source remains MIT. Changed filter lists must retain attribution and a compatible share-alike license.

YTMusic+ uses only network filters and its own small cosmetic stylesheet. It does not execute EasyList scriptlets or redirects. The matching engine is Ghostery's `@ghostery/adblocker`, under MPL-2.0; its license is included in the installed dependency.
